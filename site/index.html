The tablet can be the server

The server runs inside the app. Calendar links and tokens stay in its own private storage.

Or one server for the family

Run it with Docker. Each household is its own folder, and its secrets can be sealed with a key kept off the disk.

Either way

No cloud run by anyone else holds them, and nothing is tracked. In an outage the wall keeps the last good screen and says from when.
