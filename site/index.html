Whatever screen you have

Ours is a 15.6-inch photo frame that was $50 on Amazon. An old tablet in a drawer, an eBay or Goodwill find: any Android touchscreen from 8.0 on will do.

The tablet is the server

Gingham runs its own server inside the app. No computer, no hub, no account. Calendar links and tokens stay in the app's own private storage.

No Gingham cloud

Nothing is tracked and nothing phones home. Free and open source under the AGPL, with signed builds on GitHub. In an outage the wall keeps the last good screen and says from when.

Lists, at the wall or from a phone.

Kept by Gingham, or in the list app you already use. Check things off with a moment to undo.

What it runs on.

Any Android
8.0 or later, on a photo frame or a tablet. Built and tested on a 15.6-inch, 1920 × 1080 photo frame with Android 8.1 and 1 GB of memory.
The install
An APK from the latest release, about 22 MB, not an app store. Most frames want gingham-32bit.apk; gingham-either.apk runs on any Android.
Check first
A few photo frames lock their launcher so nothing else can be installed. Look for one that lets you install an APK, or use a tablet.

Plain Node. No packages. No build step.

One small program, on the frame or in a container.

Read the docs Docker image

Open source, and early.

The code is on GitHub under the AGPL-3.0, with signed builds of the app and a container image in its releases.
