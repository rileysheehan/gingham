- Screen time: a child's minutes for the day in a ring on the wall, counting down in minutes and seconds.
- A timer anyone can start and stop. It stops by itself when the time runs out, and the frame plays a short chime.
- Adding or taking away time, and changing the daily allowance, take the household PIN.
- Every change goes in the day's record, and starting or stopping the timer can be undone for a few seconds.

Screen time is off until a grown-up turns it on in Settings → Screen time, which needs a household PIN set on the
setup page first. It keeps time only while its timer runs; it never measures a device. On a frame that runs the app,
install this one from Settings → Updates: it updates in place and keeps the frame paired. Calendars, lists, photos and
settings from 0.2.1 carry over as they are.
